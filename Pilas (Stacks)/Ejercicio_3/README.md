# El Historial del Navegador Web
**Enunciado:** Simula el comportamiento de los botones "Ir a página" y "Atrás" de un navegador web. El usuario puede escribir una URL para visitarla, o escribir la palabra "atrás" para regresar a la página anterior. Usa una pila para almacenar el historial de navegación de modo que el comando "atras" te devuelva siempre la última página visitada.
- **Qué practicas:** Simulación de estados y manejo de flujos basados en LIFO.
